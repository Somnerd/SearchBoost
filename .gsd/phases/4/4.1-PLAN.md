# Plan 4.1: Warden Build Acceleration (Docker Caching & Dev-Mode)

## Objective
Convert `searchboost_warden/Dockerfile` into an optimized multi-stage build capable of dependency caching (e.g., using `cargo-chef` or bare layer caching) to eliminate the 25-minute build penalty. Introduce an environment toggle to allow standard `debug`/development builds instead of forcing `--release`.

## Context
- .gsd/SPEC.md
- docker-compose.yml
- searchboost_warden/Dockerfile

## Tasks

<task type="auto">
  <name>Implement Multi-Stage Caching (Warden)</name>
  <files>searchboost_warden/Dockerfile</files>
  <action>
    Refactor the Dockerfile using best practices for Rust caching.
    - If installing `cargo-chef`, utilize the planner, recipe, and builder stages to firmly cache the `dependencies` layer before touching the `src/` files.
    - Pass an `ARG BUILD_PROFILE=release` build argument to control how it compiles.
  </action>
  <verify>Check `searchboost_warden/Dockerfile` using view_file to confirm the stages are applied correctly.</verify>
  <done>Changes to `src/main.rs` don't trigger re-downloading of dependency indices if Cargo.toml has not changed.</done>
</task>

  <name>Docker Compose Dev-Mode Profiles</name>
