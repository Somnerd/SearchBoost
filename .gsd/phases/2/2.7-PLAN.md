# Plan 2.7: Admin Panel

<objective>
Build the admin panel with two sections: User Management and System Health.
This is only accessible to users with role=admin. The panel integrates with
real backend endpoints from Plan 2.3.

Design: Two-column layout on wide screens, single column on mobile. Glass cards
for each section. Status indicators with color-coded badges.

Purpose: Give the admin visibility and control over users and system state.
Output: Fully functional admin panel page.
</objective>

Load for context:
- searchboost_ui/src/index.css
- searchboost_ui/src/api/client.js
- .gsd/phases/2/2.3-PLAN.md  (admin endpoint shapes)
</context>

<tasks>

<task type="auto">
  <name>AdminUserTable component</name>
  <files>searchboost_ui/src/components/AdminUserTable.jsx</files>
  <action>
    Props: { users[], currentUser, onRoleChange(id, newRole), onDelete(id), loading }

    Renders a table (or card list on mobile) with columns:
    | Username | Role | Joined | Actions |

    Role column: badge with color (admin=accent blue, user=text-muted background)

    Actions column for each row (disabled for currentUser's own row):
    - Toggle Role button:
      * If user.role === "user" → "Make Admin" button (accent)
      * If user.role === "admin" → "Make User" button (warning orange)
      * Own row: both buttons disabled, tooltip "Cannot modify own account"
    - Delete button (.btn-danger "Delete"):
      * Own row: disabled
      * Others: click → inline confirmation "Are you sure? [Confirm] [Cancel]"
        → on Confirm: call onDelete(id)

    Loading state: skeleton rows (pulsing grey placeholders) while fetching.

    Styling:
    - Table: full-width, glass card wrapper
    - Row hover: subtle background highlight
    - Actions: compact icon buttons or small text buttons with gap

    AVOID: Deletion without confirmation — data loss requires explicit confirmation.
    AVOID: window.confirm() — use inline confirm UI.
  </action>
  <verify>Render with mock users array. Toggle role and delete buttons fire correct callbacks.</verify>
  <done>Role toggle shows correct label per current role. Own row buttons are disabled.</done>
</task>

<task type="auto">
  <name>SystemHealth component + Admin page assembly</name>
  <files>
    searchboost_ui/src/components/SystemHealth.jsx
    searchboost_ui/src/pages/Admin.jsx
  </files>
  <action>
    `SystemHealth.jsx`:
    Props: { health, loading, lastUpdated }
    health shape: { warden: { status, circuit_breaker }, database: { status }, timestamp }

    Renders a glass card "System Health" with:
    - Warden row: green dot "Healthy" or red dot "Unreachable" + circuit_breaker badge
      ("OPEN" in warning red, "CLOSED" in green)
    - Database row: green/red status
    - "Last updated: {relative time}" in text-muted
    - "Refresh" button that triggers a manual health check
    - If loading: pulsing skeleton
    - Auto-refreshes every 30s via useEffect with setInterval

    `Admin.jsx`:
    - Page header: "Admin Panel" H1 + subtitle "Manage users and monitor system health"
    - Tabs or two-section layout:
      Section 1: "User Management" — renders AdminUserTable
      Section 2: "System Health" — renders SystemHealth

    Data fetching:
    - On mount: GET /api/admin/users → setUsers
    - On mount: GET /api/admin/health → setHealth
    - Health auto-refresh: setInterval(fetchHealth, 30000), cleared on unmount

    Role change handler (calls PATCH /api/admin/users/:id/role):
    - Optimistic update: immediately toggle in UI
    - On error: revert + show error toast message

    Delete handler (calls DELETE /api/admin/users/:id):
    - On success: remove from users state
    - On error: show error message

    Toast notification system (simple fixed-corner div):
    - Green for success, red for error, auto-dismiss after 3s

    AVOID: Polling /users every 30s — users list only needs refresh after mutations.
    AVOID: Forgetting to clear the health interval on component unmount.
  </action>
  <verify>
    Log in as admin → /admin
    - Users table loads with all registered users
    - Health panel shows Warden + DB status (green if services running)
    - Promote a user → badge updates immediately
    - Delete a user → confirmation inline → user removed from table
    - Health auto-refreshes (check Network tab for periodic requests)
  </verify>
  <done>
    All admin operations work without page refresh.
    Health panel updates every 30s.
    No memory leaks (interval cleared on unmount, test by navigating away and back).
  </done>
</task>
