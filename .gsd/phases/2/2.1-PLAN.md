<task type="auto">
  <name>Bootstrap Node.js Express API project</name>
  <files>
    searchboost_api/package.json
    searchboost_api/src/app.js
    searchboost_api/.env.example
  </files>
  <action>
    Run: `mkdir -p searchboost_api/src/{routes,middleware,db} && cd searchboost_api && npm init -y`
    Install: `npm install express bcrypt jsonwebtoken cookie-parser cors pg dotenv`
    Install dev: `npm install -D nodemon`

    Create `src/app.js`:
    - Express app with `cookie-parser`, `cors` (origin: process.env.UI_ORIGIN, credentials: true),
      `express.json()` middleware
    - Mount routes: /api/auth → authRouter, /api/search → searchRouter, /api/admin → adminRouter
    - GET /health → { status: "healthy", timestamp }
    - Error handler middleware at bottom
    - Listen on process.env.PORT || 3001

    Create `.env.example` with:
      PORT=3001
      DB_HOST=sb_db
      DB_PORT=5432
      DB_USER=searchboost
      DB_PASSWORD=searchboost_pass
      DB_NAME=searchboost_db
      JWT_SECRET=change_me_to_a_long_random_string
      JWT_EXPIRES_IN=24h
      UI_ORIGIN=http://localhost:5173
      WARDEN_URL=http://sb_warden:14141

    Add to package.json scripts:
      "start": "node src/app.js"
      "dev": "nodemon src/app.js"

    AVOID: Using `import`/ESM syntax — use CommonJS `require()` throughout. Node.js
    in Docker with default config uses CJS. Prevents `ERR_REQUIRE_ESM` at runtime.
  </action>
  <verify>cd searchboost_api && node src/app.js &amp; sleep 2 &amp;&amp; curl http://localhost:3001/health</verify>
  <done>GET /health returns 200 with { status: "healthy" }</done>
</task>

<task type="auto">
  <name>Create pg pool + users table + query helpers</name>
  <files>
    searchboost_api/src/db/pool.js
    searchboost_api/src/db/users.js
    searchboost_api/src/db/migrate.js
  </files>
  <action>
    `src/db/pool.js`: Export a `pg.Pool` using env vars (DB_HOST, DB_PORT, etc.).

    `src/db/migrate.js`: On startup, run CREATE TABLE IF NOT EXISTS:
    ```sql
    CREATE TABLE IF NOT EXISTS users (
      id          SERIAL PRIMARY KEY,
      username    VARCHAR(64) UNIQUE NOT NULL,
      password_hash TEXT NOT NULL,
      role        VARCHAR(16) NOT NULL DEFAULT 'user',
      created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
    );
    ```
    Call this from app.js startup (before listen).

    `src/db/users.js`: Export these async functions using the pool:
    - findByUsername(username) → single user row or null
    - createUser(username, passwordHash) → inserted user row
    - listUsers() → all users (id, username, role, created_at — NOT password_hash)
    - updateRole(id, role) → updated user row
    - deleteUser(id) → void

    AVOID: Selecting password_hash in listUsers() — never send hashes to the client.
    AVOID: Creating a new Pool per-request — import the singleton pool everywhere.
  </action>
  <verify>node -e "require('./src/db/pool.js').query('SELECT 1').then(() => console.log('DB OK'))"</verify>
  <done>Pool connects, migrate.js creates users table without error on repeat runs (IF NOT EXISTS is idempotent)</done>
</task>
