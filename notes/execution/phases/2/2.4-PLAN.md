# Plan 2.4: React App Scaffold + Auth Context + Layout

<objective>
Bootstrap the React frontend using Vite, set up routing, global auth state,
and the shared layout components. This plan establishes the structural skeleton
that all page plans will slot into.

Design system: Dark glassmorphism theme. Deep navy/slate background (#0a0f1e),
glass cards (rgba white with backdrop-filter blur), electric blue accent (#4f8ef7),
Inter font from Google Fonts. Smooth entrance animations.

Purpose: Provide routing, auth state, and shared layout before building pages.
Output: Working Vite app that navigates between routes and knows who is logged in.
</objective>

<context>
Load for context:
- .gsd/phases/2/2.2-PLAN.md  (auth API endpoint shapes)
- docker-compose.yml  (frontend will be on port 5173 in dev)
</context>

<task type="auto">
  <name>Bootstrap Vite React project + install deps</name>
  <files>
    searchboost_ui/package.json
    searchboost_ui/vite.config.js
    searchboost_ui/index.html
    searchboost_ui/src/main.jsx
  </files>
  <action>
    Run: `npm create vite@latest searchboost_ui -- --template react`
    Then: `cd searchboost_ui && npm install`
    Then: `npm install react-router-dom axios`

    Update `vite.config.js` to proxy /api calls to the Node.js API:
    ```js
    server: {
      proxy: {
        '/api': {
          target: 'http://localhost:3001',
          changeOrigin: true,
        }
      }
    }
    ```
    This allows the React dev server to forward API calls without CORS issues during development.

    Update `index.html`:
    - title: "SearchBoost"
    - Add Google Fonts link: Inter 400, 500, 600, 700
    - Add meta description for SEO

    `src/main.jsx`: Wrap App in BrowserRouter from react-router-dom.

    AVOID: Using CRA (create-react-app) — unmaintained and slow.
    AVOID: Hardcoding the Node.js API URL in components — always use the /api prefix
    with the Vite proxy so it works identically in dev and production.
  </action>
  <verify>cd searchboost_ui && npm run dev -- exits with no errors, localhost:5173 responds</verify>
  <done>Vite serves React app at localhost:5173 with no console errors</done>
</task>

<task type="auto">
  <name>Design system CSS + auth context + routing + navbar</name>
  <files>
    searchboost_ui/src/index.css
    searchboost_ui/src/api/client.js
    searchboost_ui/src/context/AuthContext.jsx
    searchboost_ui/src/components/ProtectedRoute.jsx
    searchboost_ui/src/components/NavBar.jsx
    searchboost_ui/src/App.jsx
  </files>
  <action>
    `src/index.css` — Full design system:
    - CSS variables: --bg-deep (#0a0f1e), --bg-glass (rgba(255,255,255,0.05)),
      --border-glass (rgba(255,255,255,0.1)), --accent (#4f8ef7),
      --accent-hover (#3a7be0), --text-primary (#f0f4ff), --text-muted (#8892a4)
    - body: bg-deep, Inter font, color text-primary
    - .glass-card: background var(--bg-glass), backdrop-filter blur(16px),
      border 1px solid var(--border-glass), border-radius 16px, padding 2rem
    - .btn-primary: accent background, hover darken, transition 0.2s
    - .btn-danger: #e05a5a background
    - Input styles: dark transparent, accent focus ring
    - @keyframes fadeInUp: opacity 0→1, translateY 20px→0, used on .page-enter

    `src/api/client.js`:
    - axios instance with baseURL "/api", withCredentials: true (sends cookies)
    - Response interceptor: on 401 response, redirect to /login

    `src/context/AuthContext.jsx`:
    - React context with: user (null or { id, username, role }), loading bool
    - On mount: GET /api/auth/me, set user or null
    - login(userData): set user state
    - logout(): POST /api/auth/logout, set user null, navigate("/login")
    - Export AuthProvider and useAuth() hook

    `src/components/ProtectedRoute.jsx`:
    - While loading: spinner centered on page
    - If !user: <Navigate to="/login" replace />
    - Else: <Outlet />

    `src/components/AdminRoute.jsx`:
    - Extends ProtectedRoute: also checks user.role === "admin"
    - If not admin: <Navigate to="/search" replace />

    `src/components/NavBar.jsx`:
    - Show only when user is authenticated (useAuth)
    - Left: "SearchBoost" logotype in accent color
    - Right: username badge + "Admin" badge (if role=admin) + Logout button
    - Glass card style, position sticky top 0, z-index 100
    - Hover effects on nav items

    `src/App.jsx`:
    - Wrap in AuthProvider
    - Routes:
      / → redirect to /search
      /login → LoginPage (public)
      /register → RegisterPage (public)
      /search → ProtectedRoute > SearchPage
      /admin → AdminRoute > AdminPage (admin only)
    - Render NavBar above Routes (NavBar hides itself when not authenticated)

    AVOID: Storing JWT in localStorage — cookies are set by the server (httpOnly).
    The client never sees or stores the token. axios withCredentials handles it.
  </action>
  <verify>

    - Blank pages with no console errors (pages not built yet is fine)
  </verify>
