# Plan 4.2: Shared YAML Configuration & Absolute Paths

## Objective

Drop the disjointed configuration (`local_ai.json`, `warden.ini`, `web_search.json`) and merge them into a solitary, type-safe YAML file, ensuring that both Python (`SearchBoostService`) and Rust (`WardenSidecar`) share an exact duplicate of configuration logic using absolute file path loaders so it breaks down no matter the launch directory.
